# TU vanwise
 
เว็บแอปบอกเวลารถตู้ออก สาย **ธรรมศาสตร์ รังสิต → ฟิวเจอร์พาร์ค รังสิต** แบบเรียลไทม์
โครงงานวิชา TSE100 กลุ่ม 25 คณะวิศวกรรมศาสตร์ มหาวิทยาลัยธรรมศาสตร์

## หน้าเว็บ

- **หน้าผู้ใช้** (`/`) เวลารถคันถัดไปออก + จำนวนคนรอ + ปุ่มเช็กอิน + วางแผนล่วงหน้า
- **หน้าทีมงาน** (`/#staff`, ต้องใส่ PIN) ควบคุมคิว บันทึกรถออก/รถถึง รอบรถวันนี้ (ดาวน์โหลด CSV) QR สำหรับติดท่ารถ และข้อมูลความแม่นยำ/KPI/ข้อจำกัด
- QR ที่ท่ารถลิงก์ไป `/#checkin` เปิดแล้วไปที่ปุ่มเช็กอินทันที

## สองโหมด

| | โหมดทดลอง | เซิร์ฟเวอร์จริง |
|---|---|---|
| ตั้งค่า | ไม่ต้อง | ทำตาม **SETUP-SERVER.md** (ฟรี ~20 นาที) |
| ข้อมูลคิว | อยู่ในเบราว์เซอร์นี้เท่านั้น | ทุกเครื่องเห็นคิวเดียวกันทันที |
| PIN ทีมงาน | 2525 | ตั้งเองในฐานข้อมูล |
| นาฬิกา/ผู้โดยสารจำลอง | มี (ในหน้าทีมงาน) | ไม่มี ใช้เวลาจริง |

## วิธีรันในเครื่อง

ต้องมี Node.js 20 ขึ้นไป

```bash
npm install
npm run dev        # เปิด http://localhost:3000  (หน้าทีมงาน http://localhost:3000/#staff)
npm test           # ทดสอบสูตรทำนายและกติกาคิว
npm run build      # สร้างเว็บ static ในโฟลเดอร์ out/
```

ต่อเซิร์ฟเวอร์ในเครื่อง: สร้างไฟล์ `.env.local`
```
NEXT_PUBLIC_SUPABASE_URL=https://xxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJ...
```

## ระบบทำงานอย่างไร

1. ทุกการกระทำ (เช็กอิน, ยกเลิก, รถออก, รถถึง, ล้างคิว) บันทึกเป็น “เหตุการณ์” ในตาราง `events`
2. ทุกเครื่องรับเหตุการณ์ใหม่ผ่าน realtime แล้วคำนวณคิวเองด้วยกติกาเดียวกัน (`src/lib/queue.ts`) จึงเห็นตรงกัน
3. กติการถออก (จากข้อมูลภาคสนาม 1,455 รอบ)
   - เวลาออกลงท้าย 0 หรือ 5 เสมอ (99.9% ของรอบ) → **รถเต็มตอน 11:43 ออก 11:45**
   - ไม่เต็ม → ออกเมื่อรอครบ 20 นาทีนับจากคนแรก (169 จาก 193 รอบที่ไม่เต็ม)
4. เวลาที่ทำนายใช้สถิติช่วงละ 30 นาที แยกวันธรรมดา/เสาร์–อาทิตย์ ร่วมกับจำนวนคนที่เช็กอิน (`src/lib/model.ts`) แล้วปัดเป็น 0/5 และไม่เกินกติกา 20 นาที

ผลทดสอบแบบเว้นทีละวัน (26 วัน, 1,455 รอบ): คลาดเคลื่อนเฉลี่ย 4.8 นาที ดีกว่าค่าเฉลี่ยรวม 31% เวลาจริงอยู่ในช่วงที่แสดง 86%

## อัปเดตข้อมูล

1. ดาวน์โหลด CSV จากหน้าทีมงาน → ต่อท้ายในชีตรายวันของ `data/TSE100_main.xlsx`
2. `pip install openpyxl` แล้ว `npm run model`
3. `python3 scripts/make_fixtures.py data/TSE100_main.xlsx tests/fixtures.json` แล้ว `npm test`

ค่าที่แก้เองใน `src/lib/config.ts`: `TRAVEL` (เวลาเดินทาง ตอนนี้ 20–25 นาทีจากการสัมภาษณ์) และ `PLACES` (พิกัดท่ารถ ตอนนี้ประมาณ)

```
src/lib/model.ts              สูตรทำนายจากสถิติ (ตรงกับ Python)
src/lib/backend*.ts           ตัวเชื่อม Supabase / โหมดทดลอง
src/lib/useQueue.ts           โหลด + ฟังเหตุการณ์แบบเรียลไทม์
src/components/UserApp.tsx    หน้าผู้ใช้
src/components/StaffApp.tsx   หน้าทีมงาน
src/components/DataView.tsx   ความแม่นยำ / KPI / ข้อจำกัด
scripts/build_model.py        Excel → model.json + ทดสอบความแม่นยำ
tests/                        เทสต์
```
